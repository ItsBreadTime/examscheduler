\section*{ขอบเขตและวิธีใช้คู่มือนี้}
คู่มือนี้เขียนขึ้นสำหรับบุคลากรที่ต้องจัดตารางสอบและมีทักษะพื้นฐานในการใช้
ตารางคำนวณ (เช่น ไฟล์ \file{.xlsx} หรือ \file{.csv}) โดยไม่จำเป็นต้องมีความรู้
ด้านการเขียนโปรแกรม ผู้อ่านจะได้เรียนรู้ตั้งแต่การเตรียมไฟล์ข้อมูล การตั้งค่าโครงการ
การนำเข้า การจัดตารางสอบ การอ่านผลลัพธ์ การแก้ไขเวลาสอบด้วยตนเอง การตรวจสอบและ
แก้ปัญหาที่พบบ่อย ตลอดจนการเก็บงานและการแชร์ผลงาน

\subsection*{ข้อมูลที่ใช้ในตัวอย่าง}
ตัวอย่างในคู่มือนี้ใช้ข้อมูลสังเคราะห์ทั้งหมด ได้แก่ไฟล์รายวิชา \file{managed.xlsx}
(จัดอัตโนมัติ 12 รายวิชา) ไฟล์ \file{context.xlsx} (จัดไปแล้ว 2 รายวิชา)
และไฟล์เงื่อนไข \file{rules.csv} โดยทุกชื่อวิชา กลุ่มนักศึกษา และชื่ออาจารย์
เป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการสาธิต ไม่ใช่ตารางสอบจริง
