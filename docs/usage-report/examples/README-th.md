# ชุดข้อมูลตัวอย่างสำหรับคู่มือการใช้งาน

โฟลเดอร์นี้เก็บชุดข้อมูลสังเคราะห์ (ข้อมูลสมมติ) ที่ใช้ในคู่มือการใช้งาน
ระบบจัดตารางสอบ Exam Scheduler ข้อมูลทั้งหมดสร้างขึ้นเพื่อการสาธิตเท่านั้น
ไม่ใช่ข้อมูลจริงของมหาวิทยาลัยหรือสถาบันใด

## ไฟล์ข้อมูลหลัก

| ไฟล์ | บทบาท | คำอธิบาย |
|---|---|---|
| `managed.xlsx` | จัดอัตโนมัติ | รายวิชาที่ระบบจะจัดเวลาสอบให้โดยอัตโนมัติ (12 รายวิชา) |
| `context.xlsx` | จัดไปแล้ว | รายวิชาที่ระบบจะคงเวลาสอบเดิมไว้ (2 รายวิชา) |
| `rules.csv` | เงื่อนไข | เงื่อนไขการสอบ เช่น ไม่มีสอบกลางภาค/ปลายภาค สอบเต็มวัน สอบตรงกัน |
| `courses-flat.csv` | ตัวอย่าง | ไฟล์ CSV แบบแบนสำหรับการอธิบายรูปแบบข้อมูล |

| ระดับความพยายาม | 20,000 |

## กลุ่มนักศึกษา

ใช้รหัสกลุ่ม `DEMO-A` ถึง `DEMO-I` เช่น:

- `DEMO-A` — กลุ่มของวิชา 061000001 และ 061000002
- `DEMO-C`, `DEMO-D` — กลุ่มของวิชาที่สอบตรงกัน (061000003, 061000004)
- `DEMO-E` — กลุ่มของวิชาสอบเต็มวัน (061000005)
- `DEMO-GA`, `DEMO-GB`, `DEMO-GC` — กลุ่มหลายกลุ่มของวิชา 061000007

## ชุดข้อมูลย่อย (variants)

| โฟลเดอร์ | จุดประสงค์ |
|---|---|
| `clean/` | ข้อมูลหลักที่ใช้ต่อเนื่องในบทที่ 2–8 |
| `bad-code/` | ข้อมูลที่มีรหัสวิชาผิดรูปแบบ (พร้อมไฟล์แก้ไข) |
| `missing-group/` | ข้อมูลที่ขาดกลุ่มนักศึกษา (พร้อมไฟล์แก้ไข) |
| `stale-rule/` | ข้อมูลที่เงื่อนไขอ้างถึงวิชาที่ไม่มี (พร้อมไฟล์แก้ไข) |
| `tight-calendar/` | ข้อมูลที่ปฏิทินแน่น แต่จัดได้ครบ |

## ไฟล์คาดหวัง

- `expected.json` — ค่าคาดหวังของผลลัพธ์ (จำนวนวิชาที่จัด วันที่/เวลาของวิชาหลัก
  และค่าแฮชของตาราง)
- `fixture-hashes.json` — ค่า SHA-256 ของไฟล์ข้อมูลแต่ละไฟล์

## หมายเหตุ

ข้อมูลทั้งหมดในโฟลเดอร์นี้เป็นข้อมูลสมมติที่สร้างขึ้นเพื่อการสาธิต
ชื่อวิชา ชื่ออาจารย์ รหัสกลุ่ม และวันที่ทั้งหมดไม่ใช่ข้อมูลจริงของสถาบันใด
